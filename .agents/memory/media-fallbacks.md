---
name: Media fallbacks
description: Project rule for unavailable remote product and campaign images.
---

Never use an Open Graph image or any screenshot of the website as a runtime fallback for hero, drop, FAM, or product imagery. Use a neutral branded placeholder or an abstract CSS background instead.

**Why:** A screenshot fallback visually duplicates the entire interface inside the page and makes every missing product photo look like the homepage.

**How to apply:** Keep Open Graph screenshots limited to social metadata. When a remote image is unavailable, preserve layout with the neutral KYRBIRT placeholder until a valid product-specific URL is entered in Admin.
